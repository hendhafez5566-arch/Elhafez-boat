صندوق محادثات واتساب

الرسائل الحقيقية من رقم Meta المربوط بالشركة فقط. الردود في نافذة الخدمة المسموحة.

المحادثات

اختار محادثة لعرض رسائلها

صندوق الوارد الحقيقي يبدأ في استقبال الرسائل بعد ربط WhatsApp Cloud API والتحقق من Webhook.

إرسال الرسالة لا يعني وصولها؛ التسليم يُتابَع من إشعارات Meta. بعد 24 ساعة من آخر رسالة للعميل يلزم قالب واتساب معتمد.

قوالب رسائل واتساب وموافقة العملاء

رسائل فردية بقوالب معتمدة من Meta، ولا يمكن إرسالها قبل تسجيل موافقة العميل الصريحة.

إضافة قالب معتمد

يتم التحقق من Meta عند تسجيل القالب. القوالب ذات المتغيرات لا يدعمها مرسل النسخة الحالية. الربط يحتاج رقمًا مفعلًا وتصاريح فعلية.

قوالب الشركة

موافقة العميل

إرسال قالب فردي

إرسال رسالة لقائمة كاملة غير متاح من الشاشة دي. يتم التحقق من الموافقة قبل الإرسال ومنع أكثر من قالب في 24 ساعة لنفس العميل. إضافة الرسالة للطابور لا تعني وصولها.

ربط واتساب الرسمي

الاتصال عبر Meta WhatsApp Cloud API؛ لا نستخدم أي وسائل دخول غير رسمية.

ربط رقم جديد

لا تضع التوكن في GitHub أو في ملاحظات الفريق. استخدام البيانات الحقيقية يحتاج إعداد Meta App Secret ومفتاح تشفير بالخادم.

الأرقام المرتبطة

الرابط لا يفعل الحساب التجاري أو موافقة Meta تلقائيًا؛ يجب إكمال إعداد الـWebhook وتصاريح Cloud API لدى Meta.

نموذج الحجز داخل واتساب (Flows)

تحتاج نشر Flow JSON في Meta أولًا؛ إن لم يوجد Flow منشور، يكمّل العميل طلبه برسائل البوت المعتادة.

اشتراك الشركة

تفاصيل الباقة الحالية والحدود المسموح بها — إدارة الاشتراكات من حساب مالك المنصة.

الدفع الإلكتروني والفواتير التلقائية لم يتم تفعيلهما بعد؛ الحالة الحالية تُدار يدويًا من حساب مالك المنصة.
