# F27 + F35 — actual execution observability, 2026-10-21

Additive migration 0043 extends existing transitions/messages/outboxes and audit records, not the runtime. Each engine invocation has one UUID. Explicit incoming message IDs correlate only the actual current ingress; delayed/operator continuations never claim old messages. Transaction-local settings propagate IDs to outgoing messages/queues without adding fields to provider payloads. Worker confirmations retain execution IDs. Provider acceptance means ACCEPTED_DELIVERY_UNKNOWN; only actual delivered/read receipt means DELIVERED. Website availability means AVAILABLE_READ_UNKNOWN. Historical uncorrelated records remain unknown.

The existing tenant transaction wrappers persist a bounded value-free observation in a fresh tenant transaction AFTER business rollback. Savepoint continuations record the same metadata into their parent transaction. Only SQLSTATE or EXECUTION_ERROR is retained, with node/version/execution/conversation identity; no exception text, stack, bodies, answers, URLs or credentials. Total database outage cannot persist an audit until storage returns; this is best-effort and never replaces the business failure. Rolled-back conversations have no message trace and are explicitly separate from committed funnel denominators.

Actual distinct conversations entering a node in a 7/30/90-day window form denominators; distinct contacts are separately reported. Completed means at least one committed non-waiting visit. Terminal marks completed runtime/handoff. PAUSE is explicit waiting, even though its operational conversation status is HUMAN; STOP is stopped, not completed runtime. Current OPEN session waiting has activity within 24 hours OR a future input deadline OR pending durable delay/file job OR explicit PAUSE. Abandoned means inactive 24 hours and none of these reasons to wait. STOPPED/CLOSED and HUMAN are separate current states. Historical completion can overlap a current state on loops. Branch rates are distinct conversation counts per outcome/entered, can overlap on repeated visits, and imply no causal attribution. Old events lacking classification produce unknown rather than fabricated completion percentages. Preview/mock never writes production events.

Tenant/bot/published-version-scoped APIs expose bounded metadata. Reports allow version comparisons and 7/30/90 days; max 2000 node/branch groups, newest 100 failures, latest 100 published versions. Truncation is explicit. Message view shows newest 200 records with explicit source and truncation; existing ordered step trace retains cursor paging. Canvas counts are presentation-only and open branch/error drilldown after report closes. Scope reset removes overlays/dialogs.
